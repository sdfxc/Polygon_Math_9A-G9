៤. ផលបូកមុំក្រៅនៃពហុកោណ

ទោះបីជាពហុកោណប៉ោងនោះមានចំនួនជ្រុងប៉ុន្មានក៏ដោយ (ត្រីកោណ ចតុកោណ ឬ ១០០ជ្រុង) ក៏ផលបូកនៃ មុំក្រៅទាំងអស់ របស់វាតែងតែមានរង្វាស់ថេរជានិច្ច គឺ ៣៦០ ដឺក្រេ។

១ មុំក្នុង + មុំក្រៅ = 180°

មុំក្រៅ គឺជាមុំដែលកើតឡើងរវាង ជ្រុងមួយ និង បន្ទាត់បន្លាយនៃជ្រុងដែលនៅជាប់វា។

👉 ដោយសារជ្រុងពហុកោណ និងបន្ទាត់បន្លាយរបស់វា បង្កើតបានជា "បន្ទាត់ត្រង់មួយ" (រង្វាស់ ១៨០°) នោះ មុំក្នុង និង មុំក្រៅ ដែលនៅជាប់គ្នានៅត្រង់កំពូលតែមួយ គឺជា មុំបន្ថែម (Supplementary Angles) ដែលបូកបញ្ចូលគ្នាត្រូវតែស្មើនឹង 180° ជានិច្ច។

២ សម្រាយបញ្ជាក់តាមគណិតវិទ្យា

តើហេតុអ្វីបានជាផលបូកមុំក្រៅតែងតែស្មើ 360° ទោះមានប៉ុន្មានជ្រុងក៏ដោយ? យើងអាចស្រាយបញ្ជាក់តាមពីររបៀប៖

ក. តាមពិជគណិត (Algebraic Proof)៖

  • ១. ផលបូកមុំក្នុងនិងក្រៅនៃកំពូលទាំង n ៖ Σមុំក្នុង + Σមុំក្រៅ = n × 180°
  • ២. តែយើងមានរូបមន្ត Σមុំក្នុង = (n - 2) × 180°
  • ៣. ជំនួសចូល៖ (n - 2)×180° + Σមុំក្រៅ = n × 180°
  • ៤. ពន្លាត៖ n×180° - 360° + Σមុំក្រៅ = n × 180°
  • ៥. សម្រួល n×180° ចោលសងខាង នាំឲ្យ 👉 Σមុំក្រៅ = 360°

ខ. តាមធរណីមាត្រវ៉ិចទ័រ (Vector Geometry)៖

មុំក្រៅជារង្វាស់នៃការបត់ទិសដៅវ៉ិចទ័រ (Direction Vectors) តាមគែមនីមួយៗ។ ពេលវ៉ិចទ័រធ្វើចលនាជុំវិញពហុកោណ ហើយត្រឡប់មកទីតាំងដើម វាបានបង្វិលខ្លួនមួយជុំរង្វង់ពេញ គឺស្មើនឹង ៣៦០° ឬ ២π រ៉ាដ្យង់ យ៉ាងពិតប្រាកដ។

មុំក្នុង + មុំក្រៅ = 180°

ទ្រឹស្តីរំកិលមុំក្រៅ (Angle Translation)

បើរំកិលមុំក្រៅទាំងអស់មកត្រួតស៊ីគ្នានៅចំណុច O វានឹងបង្កើតបានជារង្វង់ 360° ពេញលេញ។

ក. ការរកមុំក្រៅមួយ (ពហុកោណនិយ័ត)

ចម្លើយសំណួរទី១៖ ១២០ ដឺក្រេ

ការពន្យល់៖ រូបមន្តមុំក្នុងមួយនៃពហុកោណនិយ័តគឺ S = (n-2) × 180° / n ។ ដោយ n=6, យើងបាន (6-2) × 180° / 6 = 720° / 6 = 120°។

ចម្លើយសំណួរទី២៖ ៣ ក្រឡា

ការពន្យល់៖ ដោយសារមុំមួយមាន 120° នោះយើងយក 360° (រង្វង់ជុំវិញមួយកំពូល) ÷ 120° = 3។ នេះបញ្ជាក់ថា ឆកោណ ៣ ផ្គុំចូលគ្នាបានជិតល្អឥតខ្ចោះ 360° តែម្តង ដោយគ្មានចន្លោះប្រហោង។

ចម្លើយសំណួរទី៣៖ មានចន្លោះប្រហោង!

👉 មើលចម្លើយ៖ ហេតុអ្វីត្រូវលាយបញ្ចកោណជាមួយឆកោណ?

ការពន្យល់គណិតវិទ្យា៖ ដូចដែលយើងបានដឹងក្នុងលំហាត់សំបុកឃ្មុំ ឆកោណចំនួន៣ ជួបគ្នាមានមុំសរុប 120° × 3 = 360°។ នៅពេលដែលផលបូកមុំជុំវិញចំណុចមួយស្មើ 360° ពិតប្រាកដ ផ្ទៃនោះនឹងក្លាយជា ផ្ទៃរាបស្មើ (Flat surface) មិនអាចបត់កោងបានទេ។

  • 🌍 កម្មវិធីវាយតម្លៃសិស្សអន្តរជាតិ (PISA)៖ ដកស្រង់លំហាត់បែបត្រិះរិះពិចារណា និងការដោះស្រាយបញ្ហាក្នុងជីវភាពរស់នៅប្រចាំថ្ងៃពិតៗ (ដូចជាការសង់សំបុកឃ្មុំ ការក្រាលឥដ្ឋ និងការកាត់ផ្លាកសញ្ញា)។
  • 🚀 វិទ្យាសាស្ត្រ និងបច្ចេកវិទ្យាទំនើប៖ ឯកសារស្រាវជ្រាវទាក់ទងនឹងការអនុវត្តធរណីមាត្រក្នុងវិស័យ ក្រាហ្វិក 3D (Polygonal Modeling), បច្ចេកវិទ្យាយន្តហោះបំបាំងកាយពីរ៉ាដា (Stealth Technology), និងទ្រឹស្តីវិមាត្រទី៤ (Tesseract 4D)។

លំហាត់ធ្លាប់ចេញប្រឡងឌីប្លូម (១៩៨៩ - បច្ចុប្បន្ន)

វិញ្ញាសាប្រឡងសញ្ញាបត្រមធ្យមសិក្សាបឋមភូមិ (ថ្នាក់ទី៩) ទាក់ទងនឹងមេរៀនពហុកោណ

លំហាត់ទី១ (សម័យប្រឡង៖ ឆ្នាំ ១៩៨៩)

ផលបូកមុំក្នុងនៃពហុកោណមួយស្មើនឹង ១៨០០°។ តើពហុកោណនោះមានប៉ុន្មានជ្រុង?

👉 បង្ហាញចម្លើយ និង ដំណោះស្រាយ

ដំណោះស្រាយ៖

  • តាមរូបមន្តផលបូកមុំក្នុង៖ S = (n - 2) × 180°
  • គេមាន S = 1800° នាំឲ្យ (n - 2) × 180° = 1800°
  • n - 2 = 1800 / 180 = 10
  • n = 10 + 2 = 12 ជ្រុង
  • ដូចនេះ ពហុកោណនោះមាន ១២ ជ្រុង (ទ្វាទសកោណ)។
លំហាត់ទី២ (សម័យប្រឡង៖ ឆ្នាំ ១៩៩៥)

ផលបូកមុំក្នុងនៃពហុកោណមួយធំជាងផលបូកមុំក្រៅរបស់វាចំនួន ២ ដង។ តើពហុកោណនោះមានប៉ុន្មានជ្រុង និងមានឈ្មោះអ្វី?

👉 បង្ហាញចម្លើយ និង ដំណោះស្រាយ

ដំណោះស្រាយ៖

  • តាមរូបមន្តផលបូកមុំក្នុង៖ S = (n - 2) × 180°
  • ផលបូកមុំក្រៅនៃពហុកោណប៉ោងគឺ S' = 360° ជានិច្ច
  • តាមបម្រាប់៖ S = 2 × S'
  • (n - 2) × 180° = 2 × 360°
  • (n - 2) × 180° = 720°
  • n - 2 = 720 / 180 = 4
  • n = 4 + 2 = 6 ជ្រុង
  • ដូចនេះ ពហុកោណនោះមាន ៦ជ្រុង ដែលមានឈ្មោះថា ឆកោណ។
លំហាត់ទី៣ (សម័យប្រឡង៖ ឆ្នាំ ២០០២)

ពហុកោណនិយ័តមួយមានមុំក្រៅមួយស្មើនឹង ៣០°។
ក. តើពហុកោណនេះមានប៉ុន្មានជ្រុង?
ខ. គណនាផលបូកមុំក្នុងនៃពហុកោណនោះ។

👉 បង្ហាញចម្លើយ និង ដំណោះស្រាយ

ក. រកចំនួនជ្រុង (n)៖

  • តាមរូបមន្តមុំក្រៅមួយ = 360° / n
  • គេបាន៖ 30° = 360° / n
  • n = 360 / 30 = 12 ជ្រុង

ខ. គណនាផលបូកមុំក្នុង (S)៖

  • តាមរូបមន្ត S = (n - 2) × 180° ដោយ n = 12
  • S = (12 - 2) × 180° = 10 × 180° = 1800°
លំហាត់ទី៤ (សម័យប្រឡង៖ ឆ្នាំ ២០១៤)

គណនារង្វាស់មុំក្នុងមួយ និងមុំក្រៅមួយនៃពហុកោណនិយ័តដែលមាន ១៥ ជ្រុង។

👉 បង្ហាញចម្លើយ និង ដំណោះស្រាយ

ដំណោះស្រាយ៖

យើងមានជ្រុង n = 15

  • រកមុំក្រៅមួយ៖ 360° / 15 = 24°
  • រកមុំក្នុងមួយ៖ ដោយមុំក្នុងនិងមុំក្រៅជាមុំបន្ថែម (ផលបូក 180°)
  • មុំក្នុងមួយ = 180° - 24° = 156°
  • (ឬប្រើរូបមន្ត (15-2)×180°/15 = 13 × 12° = 156°)
លំហាត់ទី៥ (សម័យប្រឡង៖ ២៣ កក្កដា ឆ្នាំ ២០១៨)

ពហុកោណនិយ័តមួយមានផលបូកមុំក្នុងស្មើនឹង ១០៨០°។
ក. តើពហុកោណនោះមានប៉ុន្មានជ្រុង និងមានឈ្មោះអ្វី?
ខ. គណនារង្វាស់មុំក្នុងមួយ និងមុំក្រៅមួយនៃពហុកោណនោះ។

👉 បង្ហាញចម្លើយ និង ដំណោះស្រាយ

ក. រកចំនួនជ្រុង (n) និងឈ្មោះ៖

  • តាមរូបមន្តផលបូកមុំក្នុង៖ S = (n - 2) × 180°
  • គេមាន S = 1080° គេបាន៖ 1080° = (n - 2) × 180°
  • n - 2 = 1080 / 180 = 6
  • n = 6 + 2 = 8 ជ្រុង
  • ដូចនេះ ពហុកោណនោះមាន ៨ជ្រុង ដែលមានឈ្មោះថា អដ្ឋកោណនិយ័ត។

ខ. គណនាមុំក្នុងមួយ និងមុំក្រៅមួយ៖

  • មុំក្នុងមួយ = S / n = 1080° / 8 = 135°
  • មុំក្រៅមួយ = 360° / n = 360° / 8 = 45°
  • (ចំណាំ៖ ផ្ទៀងផ្ទាត់ មុំក្នុង + មុំក្រៅ = 135° + 45° = 180°)
លំហាត់ទី៦ (សម័យប្រឡង៖ ៣០ វិច្ឆិកា ឆ្នាំ ២០២០)

រង្វាស់មុំក្នុងមួយនៃពហុកោណនិយ័តមួយស្មើនឹង ១៤៤°។
ក. រករង្វាស់មុំក្រៅមួយនៃពហុកោណនោះ។
ខ. តើពហុកោណនេះមានឈ្មោះអ្វី? រកផលបូកមុំក្នុងទាំងអស់។

👉 បង្ហាញចម្លើយ និង ដំណោះស្រាយ

ក. រករង្វាស់មុំក្រៅមួយ៖

  • ដោយមុំក្នុង និងមុំក្រៅជាប់គ្នាជាមុំបន្ថែម ផលបូកវាគឺ 180°។
  • មុំក្រៅមួយ = 180° - មុំក្នុងមួយ
  • មុំក្រៅមួយ = 180° - 144° = 36°

ខ. រកឈ្មោះ និងផលបូកមុំក្នុង៖

  • តាមរូបមន្តមុំក្រៅមួយ = 360° / n
  • គេបាន៖ 36° = 360° / n ⇒ n = 360 / 36 = 10 ជ្រុង
  • ដូចនេះ ពហុកោណនេះមានឈ្មោះថា ទសកោណនិយ័ត។
  • ផលបូកមុំក្នុង S = មុំក្នុងមួយ × n = 144° × 10 = 1440°
លំហាត់ទី៧ (វិញ្ញាសាជ្រើសរើសពិសេស)

គេមានបញ្ចកោណប៉ោងមួយ (៥ជ្រុង) ដែលមានរង្វាស់មុំក្នុងចំនួនបួន គឺ ១០០°, ១២០°, ៩០° និង ១១០°។
ចូរគណនារង្វាស់មុំក្នុងទី៥ ដែលនៅសល់។

👉 បង្ហាញចម្លើយ និង ដំណោះស្រាយ

ដំណោះស្រាយ៖

  • តាមរូបមន្តផលបូកមុំក្នុងបញ្ចកោណ (n = 5) គឺ៖
  • S = (5 - 2) × 180° = 3 × 180° = 540°
  • តាង x ជាមុំក្នុងទី៥ ដែលត្រូវរក គេបាន៖
  • 100° + 120° + 90° + 110° + x = 540°
  • 420° + x = 540°
  • x = 540° - 420° = 120°
  • ដូចនេះ មុំក្នុងទី៥ ដែលនៅសល់មានរង្វាស់ ១២០°។
